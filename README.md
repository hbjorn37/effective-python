# effective-python

## 목차

- 2장. 리스트와 딕셔너리
- 3장. 함수
- 4장. 컴프리헨션과 제너레이터
- 5장. 클래스와 인터페이스
- 6장. 메타클래스와 애트리뷰트
- 7장. 동시성과 병렬성
- 8장. 강건성과 성능
- 9장. 테스트와 디버깅
- 10장. 협업
